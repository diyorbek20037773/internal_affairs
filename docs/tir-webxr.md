# TIR — режим WebXR (VR-шлем)

3D-полигон можно проходить в VR-шлеме прямо из браузера, без установки приложения. Реализация: `src/components/training/tir/xr/XrRig.tsx` (чистый `three.js` `renderer.xr`, без дополнительных библиотек), кнопка **VR** над сценой (`TirClient`).

## Поддержка

| Устройство | Браузер | Как |
|---|---|---|
| Meta Quest 2/3/Pro | Meta Browser (Chromium) | открыть сайт в шлеме → кнопка **VR** |
| ПК-шлемы (SteamVR / Windows MR / Vive) | Chrome, Edge на ПК с активным OpenXR-рантаймом | кнопка **VR** появляется, когда `navigator.xr.isSessionSupported("immersive-vr")` = true |
| Планшет / без шлема | — | кнопки нет, режимы FPS / фиксированная камера как раньше |

Сайт должен быть по HTTPS (Railway — да). Разработка: `chrome://flags/#webxr-runtime` → «WebXR emulator» или расширение *Immersive Web Emulator*.

## Управление в VR

| Действие | Контроллер |
|---|---|
| Выстрел | курок (`selectstart`) любого контроллера — луч из контроллера, попадание по зонам актёра как обычно |
| Перезарядка | боковая кнопка захвата (`squeezestart`) |
| Ходьба (только режим FPS) | левый стик — относительно направления взгляда; ограничения `clampOfficer` те же |
| Речь / команды | голос (микрофон) и клавиши 1–5 продолжают работать, кнопки панели — на планшете инструктора |
| Выход | кнопка **Выйти из VR** или системная кнопка шлема |

В фиксированном режиме рига стоит на позиции офицера, головой крутит сам обучаемый (автоприцел камеры в VR не применяется).

## Что отключается в VR

* Пост-обработка (SMAA/Bloom/Vignette) — несовместима с `WebXRManager`; включается обратно при выходе.
* Плоская «модель оружия» (`Viewmodel`) — оружие теперь контроллер.
* Pointer Lock не используется; курсор мыши — только для планшета инструктора.

## Интеграция с движком

Выстрел из VR проходит тот же путь, что клик/лазерный пистолет: `XrRig.onShoot → TirClient.onShoot → act("shoot")`. Перезарядка отправляется как `h360:input {action:"reload"}`, т.е. подхватывается тем же обработчиком, что геймпад (см. `docs/tir-input-devices.md`). Событие `h360:xr-state {presenting, error?}` сообщает UI о входе/выходе.

## Ограничения

* Комфорт: плавная ходьба стиком — у части людей вызывает укачивание; в учебных целях рекомендуем фиксированный режим + поворот тела.
* Электрошокер-пояс и лазерный пистолет работают параллельно с VR (события те же).
* Показ на трёх экранах (V-300) и VR одновременно — не поддерживается: VR-сессия занимает рендерер.
