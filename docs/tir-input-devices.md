# TIR — лазерный пистолет, триггер-бокс, геймпад

Как подключить физический спуск к 3D-полигону (`/simulyator/tir`). Реализация: `src/lib/tir/input.ts`, UI — кнопка **USB** над сценой (`InputDevicesPanel`).

## Три класса устройств

| Устройство | Как видит браузер | Что нужно |
|---|---|---|
| Лазерный пистолет с ИК-камерой (тип «light gun», эмулирует мышь) | мышь: движение + клик | ничего — работает как клик. В режиме FPS клик = выстрел в центр прицела, в фиксированном режиме — по актёру под курсором |
| Триггер-бокс / пистолет-джойстик (USB, класс HID Joystick/Gamepad) | `Gamepad API` | нажать любую кнопку → устройство появится в панели; спуск по умолчанию = кнопка 7 (RT), можно перепривязать |
| Пистолет на «сыром» USB HID (свой report descriptor) | `WebHID` (Chrome/Edge/Android Chrome) | один раз **Выбрать устройство** в панели, затем «Привязать → нажать спуск»; браузер запоминает разрешение, при следующем визите устройство подхватывается автоматически |

Bluetooth-пистолеты, представляющиеся геймпадом, работают через Gamepad API без настроек.

## Действия и привязки

`fire` (выстрел), `reload`, `draw`, `holster`, `taser`, `backup`, `cover`, `retreat`, `pause`. Привязки — в `localStorage` (`h360:tir:input:v1`), на планшет-инструктор задаются один раз.

Умолчания (раскладка Xbox): RT/B7 — выстрел, X/B2 — перезарядка, Y/B3 — достать оружие, B/B1 — шокер, LB/B4 — подкрепление, A/B0 — укрытие, Start/B9 — пауза.

## Как «выстрел» попадает в сцену

Хаб рассылает `window` событие `h360:input` `{ action, source: "gamepad"|"hid", device }`.
`ShotRaycaster` слушает `fire` и делает hit-scan из центра камеры (в FPS — куда смотрит офицер; в фиксированном режиме камера сама наводится на ближайшую угрозу). Скорострельность, магазин, перезарядка — те же, что у клика. Остальные действия обрабатывает `TirClient` так же, как клавиши F/H/T/B/R/X/Q.

Свой драйвер (например, Web Serial мост к контроллеру на Arduino) может просто отправить то же событие:

```js
window.dispatchEvent(new CustomEvent("h360:input", { detail: { action: "fire", source: "hid", device: "my-bridge" } }));
```

## Ограничения

* WebHID нет в Firefox и Safari — там остаются мышь и Gamepad API.
* Прицеливание по дотрагиванию лазера до экрана (без ИК-камеры) не поддерживается: спуск только выбирает момент выстрела, точка — центр прицела.
* На Android WebView (E-O'quv) Gamepad API доступен; WebHID — только в Chrome ≥ 89 в обычной вкладке.
