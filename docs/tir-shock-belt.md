# TIR — электрошокер-пояс (выходной адаптер)

Когда в офицера попадают (движок: `state.shockSeq`), `TirClient` поднимает `window` событие **`h360:shock`** `{ sessionId, t }` и показывает экранный «стимул» (красная виньетка, гул, вибрация планшета). `src/lib/tir/shock.ts` (`shockHub`) переводит то же событие в команду реальному поясу. Настройка — панель **USB** над сценой → блок «Электрошокер-пояс».

## Транспорты

| Транспорт | Браузер | Устройства |
|---|---|---|
| **Web Serial** (USB CDC / RS-232 / Arduino, ESP32) | Chrome, Edge ≥ 89 (десктоп); Android — нет | контроллер пояса с последовательным портом |
| **Web Bluetooth** (BLE GATT write) | Chrome, Edge, Android Chrome | BLE-пояса; service/characteristic UUID задаются в панели (по умолчанию HM-10 `FFE0/FFE1`) |

Firefox/Safari не поддерживают ни то, ни другое — там остаётся экранная имитация. Подключение требует клика пользователя (ограничение браузера); Serial-порт, разрешённый ранее, подхватывается автоматически при следующем открытии полигона (если адаптер «Включён»).

## Полезная нагрузка

Шаблон в панели, подстановки `{ms}` (длительность 1–2000) и `{level}` (сила 1–100):

* текст (по умолчанию): `SHOCK {ms} {level}\n` → `SHOCK 300 40⏎`
* байты: префикс `hex:` — `hex:AA 01 {ms16} {level} 55` → `AA 01 01 2C 28 55` (`{ms16}` — 2 байта big-endian, `{ms}`/`{level}` — 1 байт)

Кнопка **Тестовый импульс** отправляет ту же команду без сценария — для проверки на стенде. Флажок **Включён** отвечает только за реальные попадания; тест работает всегда, когда есть соединение.

## Пример прошивки (Arduino, Serial)

```cpp
void loop() {
  if (Serial.available()) {
    String line = Serial.readStringUntil('\n');      // "SHOCK 300 40"
    if (line.startsWith("SHOCK")) {
      int ms = line.substring(6, line.indexOf(' ', 6)).toInt();
      int level = line.substring(line.lastIndexOf(' ') + 1).toInt();
      analogWrite(PIN_BELT, map(level, 1, 100, 30, 255));
      delay(constrain(ms, 1, 2000));
      analogWrite(PIN_BELT, 0);
    }
  }
}
```

## Свой мост

Любой другой канал (WebSocket к локальному сервису, Web MIDI, USB-реле) — подпишитесь на событие сами:

```js
window.addEventListener("h360:shock", (e) => myBridge.pulse(e.detail));
```

После успешной отправки хаб поднимает `h360:shock-sent` `{ reason: "hit"|"test", bytes }` — удобно для журнала стенда.

## Безопасность

Пояс — медицинский/учебный стимулятор: длительность ограничена 2 с и силой 1–100 на стороне ПО, **аппаратный** предохранитель по току и таймауту обязателен на стороне устройства. Инструктор перед занятием проверяет пояс тестовым импульсом на минимальной силе.
