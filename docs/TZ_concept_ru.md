# HIMOYA-360 — концепция и ТЗ (RU)

## 1. Суть
**HIMOYA-360** — платформа сценарного симуляционного обучения сотрудников ОВД (модель Центра профессионального развития, ИИББ Шайхантахур). Цикл: **СИТУАЦИЯ → АНАЛИЗ → КОММУНИКАЦИЯ → РЕШЕНИЕ → ДЕЙСТВИЕ → РЕЗУЛЬТАТ**. Девиз: «Мы не обучаем сотрудника — мы готовим его к реальной службе».
Внутри — модуль **«Мой инспектор»** (AI-помощник профилактического инспектора: SOP, чек-листы, документы, статьи закона).

Международная база: Stockton PD (сценарные тренировки + немедленный дебрифинг), PERF ICAT (Critical Decision-Making Model), VirTra / Axon (ветвящиеся сценарии), UK Hydra (иммерсивный дебрифинг), Politieacademie NL (VR), Singapore HTA. Мы начинаем с **AI + web** (планшет Android + 4G, только браузер, без оборудования); VR — следующий этап.

## 3. Принципы (обязательные)
1. Сценарии — авторские TS-данные (`data/scenarios/`), не генерируются LLM в рантайме → детерминированная оценка, проверяемость инструктором.
2. Правовая база — только подтверждённые статьи из `data/sops/laws.ts` (lex.uz). AI не выдумывает номера статей и не делает выводов о виновности.
3. **AI не принимает решений — подтверждает инструктор.** Ошибка не наказывается: ОШИБКА → АНАЛИЗ → ОПЫТ → МАСТЕРСТВО.
4. Каждое упражнение заканчивается дебрифингом.
5. Web-first: работает в браузере планшета (Android, 4G), PWA; оффлайн-фолбэк на localStorage.
6. 3 языка UI: uz (по умолчанию) / ru / en.

## 4. Техническая архитектура
- Next.js 14 App Router, TypeScript, Tailwind, shadcn-стиль UI, next-intl, next-themes.
- AI: Gemini (`@google/genai`), пул ключей с ротацией и failover; `generateJson()` — JSON mode + zod + 1 repair-retry. Контракт ошибок: `no_keys_configured` 500 / `ai_unavailable` 503 / `bad_ai_output` 502.
- API: `/api/chat`, `/api/legal`, `/api/tts`, `/api/stt`, `/api/sim/{dialog,debrief,mahalla-grade,document-check,mentor,exam-summary}`, `/api/health`.
- Хранение: `TrainingRepo` (async интерфейс) — локальный адаптер (localStorage `h360:*`) и серверный (Postgres, `/api/store/*`), гибрид: пишем локально всегда, на сервер — если доступен. `CasesRepo` (`mi:cases:v1`) — дела модуля «Мой инспектор».
- Идентификация: профиль (ФИО, жетон SH-xxxx, звание, участок, роль trainee|instructor). Полноценный auth — отдельный этап.
- 3D: Three.js / r3f, движок `src/lib/training/tirEngine.ts` (детерминированный), ассеты RPM + Poly Haven скачиваются на `prebuild`.

## 5. Интеграции (следующие этапы)
- Планшет «E-O'quv»: HIMOYA-360 открывается по URL/WebView под кнопкой E-O'quv; `?embed=1` + postMessage мост (профиль, результат).
- Реальный лазерный пистолет (HID/Bluetooth) → событие выстрела; реальный электрошок-пояс ← событие `h360:shock`.
- Видеопаки с реальными актёрами (`docs/tir-video-pack.md`).
- VR-режим (WebXR) после стабилизации веб-версии.
